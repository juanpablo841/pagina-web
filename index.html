¿Cómo funciona una página web?

Una página web se construye con tres lenguajes que trabajan juntos: HTML (estructura), CSS (estilo) y JavaScript (comportamiento). Prueba los ejemplos en vivo de abajo.

🟩 Jugar PixelBox (mundo de píxeles)

🌐 El camino de una página web

Cuando escribes una dirección en el navegador, esto pasa detrás de escena:

⌨️Escribes la URL
→
📡El navegador pide el archivo al servidor
→
📄El servidor envía HTML, CSS y JS
→
🖥️El navegador los interpreta y dibuja la página

H HTML: la estructura

El HTML define qué elementos hay en la página: títulos, párrafos, botones, imágenes. Es el "esqueleto".

<h1>Hola</h1>
<p>Este es un párrafo.</p>
<button>Haz clic</button>

Cada etiqueta (<h1>, <p>, <button>...) le dice al navegador qué tipo de contenido mostrar.

C CSS: el estilo

El CSS decide cómo se ve cada elemento: colores, tamaños, espaciado, posición.

button {
  background: #38bdf8;
  border-radius: 8px;
  padding: 10px 20px;
}

JS JavaScript: el comportamiento

El JavaScript hace que la página reaccione: responde a clics, actualiza datos, valida formularios, sin recargar la página.

let contador = 0;
boton.addEventListener("click", () => {
  contador++;
  texto.textContent = contador;
});
